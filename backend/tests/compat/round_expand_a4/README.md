# Замороженная граница A4

`source/**/*.py.fixture` — побайтовые копии реальных модулей из коммита
`fba895ed0447fe7ad4bdebcfd1fd9f3acd54df4f`. В `manifest.json` указаны исходные пути,
ревизия и SHA-256 каждого файла. Это минимальное рекурсивное дерево импортов для
обычных команд Round и SQL adapter, snapshot, authenticated ReadMessages и его GET
router, SQL history/current_packet и typed readers media outbox. Main, HTTP-сервер,
миграции и LiveKit SDK adapter в копии не входят.

Исторические исходники неизменяемы: не исправлять, не форматировать и не обновлять
их вместе с текущим приложением. Расширение `.py.fixture` отделяет их от активного
Python. Для новой границы совместимости нужен отдельный набор.

`run_a4.py.fixture` — текущий тестовый harness, а не исторический исходник A4. Тест
материализует исходники в собственном временном каталоге и запускает отдельный
Python с этим пакетом первым в PYTHONPATH и с временным рабочим каталогом. До и
после работы harness проверяет путь каждого загруженного модуля `debatemeet` и
отсутствие B4-команды `Round.draw`.

Тест создаёт состояние настоящими B4-командами и chat use cases в отдельной
временной базе Postgres со схемой 0004. A4 выполняет обычные Enter и PauseTimer через
свой executor, проверяет authenticated snapshot/history, ASGI GET200 и POST405 без
порта сервера, читает typed removal/packet heads и разрешает B4 chat/delete packets.
B4 затем читает ту же базу, проверяет сохранность motion/drum/undo/chat и продолжает
жеребьёвку и undo. JSON golden получены настоящими serializer и router A4; в них
только синтетические публичные данные.

Git нужен только при первоначальном извлечении и проверке происхождения. Во время
тестов нет зависимости от истории Git, внешней сети, второго сервера или `.env`.
URL временной базы и синтетические credentials передаются subprocess через stdin,
не входят в публичные golden и не печатаются в диагностике ошибок.
