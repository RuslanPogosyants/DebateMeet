# Замороженный исходный код границы A

Файлы `source/**/*.py.fixture` — побайтовые копии минимального дерева импортов
`round.infrastructure.mapper` и `round.contract.snapshot` из коммита
`ca18693ea72b5ddf7499448fcf8b71e39bac0f34`. Это настоящие mapper, домен и сериализатор
подготовительной поставки A, без команд изменения таймеров из B. `manifest.json`
содержит исходные пути, ревизию и SHA-256 каждого файла.

Копии намеренно имеют расширение `.py.fixture`: форматтеры, линтеры и обычный импорт
Python не должны изменять или исполнять исторический код как текущий модуль.
Не исправляйте эти копии при изменении приложения. Если потребуется новая граница
совместимости, добавьте отдельный набор, сохранив этот.

`test_timer_rollback.py` проверяет контрольные суммы, материализует пакет только во
временном каталоге и запускает отдельный Python с этим каталогом первым в
`PYTHONPATH`. Процесс проверяет пути всех загруженных модулей `debatemeet` и отсутствие
команд B. Он читает состояние, созданное командами B, выполняет обычный `enter` A,
записывает его mapper A и строит публичный снимок настоящим `snapshot_of` A.
Состояние затем снова читает B; общий JSON-снимок также проверяет клиентский parser B.
Тест проверяет совместимость данных и транспорта; SQL-транзакции проверяются отдельно.

Git нужен только для первоначального извлечения и проверки происхождения копий.
Во время тестов история Git, сеть и второй сервер не используются: squash merge и
удаление ветки не лишают проверку её исторического основания.
