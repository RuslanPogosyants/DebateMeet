# Единая левая панель и компактные элементы плиток

Версия плана v1.1, 30.10.2026. Автор поручил реализацию после пояснения в чате. Основа — текущий HEAD и рабочие изменения записи/сворачивания комнат; их сохраняем. Только frontend UI, CSS, связанные проверки и документация. Backend, RTC, запись, громкость и команды не меняются.

## Выбранное поведение

Комнаты и общий чат/жребий составляют одну левую колонку шириной около 300 px на desktop, 280 px на compact. Комнаты сверху, чат занимает оставшуюся высоту с собственным скроллом истории. Карта компактнее существующей, но текст не меньше 13 px. Правая колонка исчезает, сцена получает всю остальную ширину. При невысоком экране карта ограничена долей высоты и прокручивается отдельно, чтобы поле ввода чата оставалось достижимым. При слишком малой высоте прокручивается панель целиком, ничего не обрезается без доступа.

Один постоянный переключатель в заголовке сцены скрывает/возвращает всю левую панель. На ширине до 959 px этот же контент открывается в существующем Sheet слева, без узкой колонки рядом с видео. Кнопка чата открывает ту же панель и выбирает чат; отдельного закрытия чата больше нет. При переходе между ширинами сохраняется desktop-выбор сворачивания; мобильная панель по умолчанию закрыта. Переход в другую комнату через мобильную карту закрывает Sheet. Escape и закрытие возвращают фокус на вызвавшую кнопку. Черновик хранится существующим chat controller; скрытый чат не считается прочитанным.

Плитки сохраняют существующие video elements и attachVideo. Микрофон on/off маленьким постоянным значком показывается и у себя, и у других. Имя и состояние накладываются на нижнюю часть изображения с полупрозрачным градиентом. Пин/персональная громкость/скрытие камеры/многоточие — компактные кнопки без наружных рамок поверх изображения. Для мыши появляются по hover/focus-within; закрепленный пин и открытое меню остаются обозначены. На touch всегда доступны; иконка 16–18 px при достаточной зоне нажатия (32 px mouse, 44 px coarse pointer). Полные подписи aria-label и меню сохраняются. Для миниатюр остаются существующие container rules и полное меню.

## Приемка

1. На 1600×1000, 1280×720 и 1024×768 слева комнаты над чатом, справа только сцена; поле ввода доступно, нет горизонтального скролла. На 390×844 тот же состав в левом Sheet, видео остается отдельным.
2. Collapse скрывает одновременно карту и чат, restore сохраняет черновик. Кнопка чата открывает панель и выбирает chat даже после вкладки жребия. Таб-навигация не попадает в скрытые элементы; focus после Sheet/Escape возвращается к trigger.
3. Collapse/restore/чат не заменяют camera/screen DOM, не меняют pin/grid/self-view и не вызывают RTC или domain commands. На resize карта и чат остаются доступны.
4. На большой плитке маленькие значки не обведены большими кругами. Статус mic и имя видны всегда; actions доступны hover/keyboard/touch, pressed pin и открытые controls не пропадают. Volume popup сохраняет рабочий фокус и внешний dismiss.
5. Проверка настоящей сборки с искусственными участниками/видео на нескольких размерах, визуальный просмотр снимков и замер увеличения сцены. UI tests покрывают совместное сворачивание, сохранение draft/media, чат после drum и resize; CSS hover/geometry проверяются в браузере. Полный frontend test/lint/types/layers/build/budget. Длительные и звуковые прогоны не нужны; в браузере фиктивный audio output.

Примеры: Google Meet документирует pin при наведении на плитку (https://support.google.com/meet/answer/7501121); Телемост использует действия при наведении на участника (https://yandex.by/support/yandex-360/customers/telemost/web/ru/administration). Это ориентир поведения, не копирование визуального стиля.


## Результат независимого ревью

Инженерное ревью v1 подтвердило существующие точки переиспользования и отсутствие новой инфраструктуры. Behavioral review выявило риск reading у чата, уехавшего из видимой области на низком экране. В v1.1 ChatPanel наблюдает IntersectionObserver за небольшим sentinel в конце истории; reading разрешен только при полной видимости sentinel (видимость только верхней части log недостаточна), видимом документе и достигнутом низе истории. Начальное значение до первого измерения — false; браузер без IntersectionObserver использует существующий fallback. Наблюдатель отключается при unmount. Проверяется регрессией: offscreen сообщение остается непрочитанным до пересечения видимой области у низа истории. Обе проверки плана read-only, реализация авторизована исходным запросом.


## Реализация и проверка

Реализован описанный UI без изменения backend, RTC, локальной записи и громкости. `RoundSidebar` выводит активную вкладку из пользовательского выбора и номера запроса чата, без эффектов с setState. При смене layout открытый мобильный Sheet закрывается; desktop-выбор остается. Поле ввода и черновик сохраняются; скрытый ChatPanel размонтируется с cleanup reading. Для проверки видимости наблюдается однопиксельный sentinel в конце истории, а не доля видимости всего log.

Полный frontend: **678 тестов прошли**; type-aware lint, typecheck, dependency-cruiser, production build и format check прошли. Initial JavaScript **119.3 KiB gzip** при бюджете 150 KiB. После последних CSS-уточнений повторно прошли 12 целевых проверок theme/collapse/reading. Полный backend и весь E2E-набор не запускались: backend не менялся, пользовательский сервер не перезапускался.

Браузерная проверка собранного приложения на настоящих локальных backend/Postgres/LiveKit с собственным раундом и восемью ботами: 1600×1000, 1280×720 и 1024×768. Камеры/движущаяся демонстрация искусственные, аудиовыход Chromium фиктивный, физические устройства не захватывались. Карта сверху чата, горизонтального скролла нет, поле ввода доступно. Ширина сцены при открытой панели соответственно 1256/964/708px. Сворачивание на 1600px дает еще **312px**. Camera и screen DOM сохранились при сворачивании, открытии чата и resize на телефон. Draft и выбор chat после drum сохранены. Кнопки mouse 32×32 без рамки, hover и keyboard focus проверены; на touch 44×44 и постоянная доступность. На 390×844 панель находится у левого края, поле чата видно целиком, Escape возвращает фокус на trigger. Ошибок страницы нет.

Браузерная проверка выявила и закрыла два CSS-несоответствия: прежний min-width многоточия мешал уменьшению, а отсутствие flex-height у содержимого мобильного Sheet скрывало composer. Снимки после исправлений просмотрены визуально. Свои браузеры и preview закрываются; рабочее приложение остается на http://localhost:5173. Merge/deployment не выполнялись.
