# Записи о решениях (ADR)

ADR — короткая запись о крупном решении: что решили, почему и чем за это платим. Она нужна, когда решение меняет то, что уже записано в [спеке](../spec.md) или [архитектуре](../architecture.md), или когда его будут пытаться пересмотреть.

- Сначала решение обсуждается с автором, потом записывается.
- Файл — `NNNN-коротко-о-решении.md`, номера идут подряд. Начинать с копии [0000-template.md](0000-template.md).
- Принятую запись не переписывают. Если решение меняется, пишут новую запись, а у старой меняют статус на «заменено NNNN».
- После принятия спека и архитектура приводятся в соответствие; запись остаётся историей того, почему так.
