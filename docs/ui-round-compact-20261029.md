## Наблюдения и решение

Использовать contain для видео и отдельную компактную подпись в потоке, выделить видео собственную оставшуюся область. Сохранить элемент video/attachVideo. Превью и своя плитка получают CSS scaleX(-1), удаленные не зеркалятся; на передаваемый поток CSS не влияет.
- ReactionControls уже содержит список из пяти реакций и доступные имена/ограничения. Показывать список сразу в footer на всех размерах; убрать details и expanded вариант. Настройку скрытия реакций перенести в настройки.
- В Meeting убрать desktop-diagnostics-actions, вместо них шестеренка 44px в правом углу шапки. Использовать существующий Sheet для настроек с checkbox скрытия реакций и входами в DiagnosticsPanel/ProblemReport. SoundControls остается отдельной кнопкой вне settings (ревью подтвердило, что вложение создаст второй modal). При переходе между листами не оставлять вложенных modal. Клавиатурный shortcut диагностики сохраняется.
- Микрофон/камера: inline SVG с aria-hidden, кнопки 52px, доступные имена и aria-pressed/busy сохраняются, title для подсказки. Реакции: видимый круг 36px в кликабельной области >=44px; на телефоне вторая строка footer, без горизонтального переполнения. Hand/chat/more/leave сохраняют существующие действия. SoundControls доступен из прежних footer и phone More.
- Первоначальная подсветка (заменена уточнением автора ниже): первоначальная трактовка - контур значка на карте при нахождении автора в базе, в подкомнатах без подсветки. Самостоятельные UI-правки выполняются пока ожидается уточнение. Не создавать индикацию говорящих из чужой комнаты (нет подписки/сведений).

## Приемка
1. Видеокадр целиком вписывается в область, подпись его не закрывает; своя картинка зеркальная, чужая прямая, это же применяется к превью.
2. Реакция отправляется одним нажатием с прежней серверной логикой/лимитами; emoji видны без открытия меню, включая телефон.
3. Диагностика/отчет доступны из угловой шестеренки; закрытие по Escape и возврат фокуса через Sheet, shortcut диагностики работает. Настройка скрытия реакций доступна здесь.
4. Кнопки mic/camera читаемы скринридером, сохраняют pending/cancel, иконка с перечеркиванием при off; не меньше reaction targets.
5. После уточнения подсветка реагирует на speaking и исчезает в нужных комнатах, без изменения подписок.
6. Проверить 1440, 1366, 720, 390px: нет перекрытий/overflow. UI unit regression для меню/прямой реакции/подсветки; frontend tests/type/lint/layers; браузерная проверка кадра, зеркальности, размеров, меню/фокуса. Физическое качество захвата не выдается за проверенное.

## Дополнение v2: разгрузка интерфейса
Автор просит более компактную и дружелюбную компоновку по примеру Meet/Телемоста, сворачиваемый чат, меньшую высоту таймеров и неизменную ширину шкалы при любой длительности. Официальные справки обоих продуктов подтверждают вход в чат отдельной кнопкой нижней панели.
Решение: сохраняем направление Реплика/палитру, уменьшаем отступы/размер крупных цифр таймера до 48px и 40px на узких экранах. Одинаковые колонки readouts независимо от того, какой таймер запущен; ширина speech-scale всегда 100% колонки, доли уже вычисляются в процентах от duration + grace. Конечный указатель ограничивается краями, временные лимиты/семантика/команды не меняются. Пример автора 40 минут означает масштабирование, не запрос расширить доменные лимиты.
Чат: на desktop/compact кнопка footer открывает/закрывает всю правую панель и показывает unread. Панель изначально открыта для совместимости, но теперь всегда с tabs chat/drum (существующий RoundSidebar tabs), без одновременной громоздкой жеребьевки. При закрытии правая колонка исчезает, сцена расширяется; чат размонтируется, его draft/история остаются в controller.chat.store, reading сбрасывается существующим cleanup. Кнопка закрытия в шапке панели возвращает фокус footer-trigger. На узких экранах сохранен Sheet. Tablist/шапка находятся вне прокручиваемого контента; прокручивается log, не шапка. Проверить малую высоту и длинный чат/судейский жребий.
Уменьшаем общие промежутки, показ пустой очереди рук компактной строкой вместо карточки. Устройства/раскладка сохраняют доступные подписи. Новые сервисы/зависимости не вводятся. Приемка: toggle sidebar расширяет сцену, сохраняет черновик/unread, обе вкладки доступны, заголовок не обрезается; шкала одной ширины при допустимых разных длительностях/idle/running/grace/overtime, не вызывает overflow. ### Выбранный минимальный путь
Использовать существующий общий timers.prep и команды timers/prep/start,pause,reset,configure через RoundController.command с прежними auth/Idempotency-Key/pending/uncertain. Новый API, БД и миграция не нужны. Поля speechNo/speechUndo/timers.speech остаются в совместимом wire-формате; текущий UI их не использует. Новые раунды уже получают prep=15:00. Configure атомарно меняет duration и remaining и останавливает таймер; reset возвращает последнюю выставленную длительность. Нельзя заменять это цепочкой pause/set с частичным исходом.
Редактирование - input поверх цифр только для держателя флага, при focus/select выделяется значение; пока идет edit draft не перетирается новым snapshot/тикающими часами. Enter или blur применяет одно валидное значение; Escape отменяет без команды. Диапазон текущего configure 1:00–30:00, malformed секунды (1:60), 0/отрицательные/слишком большие значения показывают inline ошибку без команды. При apply blur после Enter не дублирует команду (ref guard); отмена Escape тоже блокирует blur-save. За async отвечает существующий controller, UI не показывает успех раньше snapshot. Если flag потерян/начался reconnect/command uncertain, input закрывается без отправки, readout остается, кнопки disabled/спрятаны по полномочиям. При внешнем обновлении не сохраненного draft он остается до явного save/Escape; save означает явную замену общего timer.
Одно поле и набор controls только в RoundTimers, включая narrow. Убрать прежние TimerControls/TimerReadouts из JudgeControl Sheet, старые редакторы/next/undo из UI. Никакой локальной optimistic duration. Display countdown к нулю, ноль остается 0:00 с текстом «Время вышло», backend не останавливается сам и не выполняет бизнес-действий. До нуля отображаем оставшиеся секунды с ceil, чтобы не показывать 0:00 раньше конца. Title обновляется тем же countdown. Scale фиксированной ширины, проценты elapsed/duration, без protected/POI/grace. Reset начатого таймера сохраняет подтверждение (устоявшаяся защита).
